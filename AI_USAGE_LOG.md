
# AI Usage Log

## Penggunaan Artificial Intelligence

AI digunakan sebagai alat bantu dalam praktikum
Pemrograman Web.

### Bantuan yang Digunakan

1. Membantu menyusun struktur HTML semantik.
2. Memberikan contoh penggunaan elemen header,
   nav, main, section, article, form, dan footer.
3. Membantu membuat desain CSS.
4. Memberikan penjelasan mengenai atribut alt
   dan label pada form.
5. Membantu menyusun dokumentasi README.md.
6. Memberikan panduan penggunaan Git dan GitHub.

### Verifikasi Mahasiswa

Mahasiswa melakukan pemeriksaan dan pengujian
secara mandiri terhadap kode yang digunakan.

Bagian yang diverifikasi:
- Struktur HTML.
- Tampilan website.
- Navigasi menggunakan tombol Tab.
- Formulir kontak.
- Tampilan gambar.
- Proses commit dan push Git.

### Catatan
AI digunakan sebagai alat bantu pembelajaran.
Hasil kode tetap diperiksa dan disesuaikan
dengan kebutuhan praktikum.
